# open-source-lab1

Git and GitHub collaboration practice.

## Goal
Practice commits, rollback, remote synchronization, branches, and pull requests.

## Workflow
1. Clone the repository with git clone.
2. Create a feature branch with git switch -c feature/readme-steps.
3. Edit files, inspect git diff, then use git add and git commit.
4. Push the branch and open a pull request into main.
5. Review the diff, merge the pull request, and run git pull --ff-only.

## Collaboration
Use Issues to describe tasks and acceptance criteria. Keep each commit focused.
